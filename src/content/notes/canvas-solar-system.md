# 首页的写实太阳系：零素材 Canvas 手绘

首页"据点"面板里原本是个简笔太阳系：行星是几颗纯色圆点，好看但假。这次整个重画（[2d3a976](https://github.com/zgy0715/zgy0715.github.io/commit/2d3a976)），约束只有一条：**不引入任何图片素材**，所有质感靠 Canvas 2D 画出来。

## 行星贴图：离屏预渲染

每帧直接画行星细节太浪费，所以每颗行星只在 resize 时画一次，渲染到离屏 canvas 当贴图（sprite），主循环里只做 `drawImage`。

每颗行星一个 painter 函数，质感全靠渐变和随机形状：

- **水星**：灰褐色球体 + 7 个随机陨石坑
- **金星**：硫黄色 + 5 条弧形硫酸云带
- **地球**：蓝色球体上随机铺 6 块陆地板块 + 7 条云层椭圆
- **火星**：橙红 + 暗色地貌 + 北极极冠
- **木星**：8 条横条纹 + 大红斑
- **土星**：6 条横条纹（环另画）
- **海王星**：深蓝 + 大暗斑 + 云丝

球体感的基础是 `shadeBody`：一个偏左上受光的径向渐变，所有 painter 都从它起步。

## 晨昏线：光照方向是算出来的

写实的关键一步。太阳在画布中心，行星在轨道上跑，所以**明暗分界线必须跟着行星位置转**。每帧对每颗行星：

```js
const lightAng = Math.atan2(cy - y, cx - x); // 指向太阳的角度
```

然后在行星圆内 `rotate(lightAng)`，沿光照轴叠一层线性渐变：朝阳侧全透明，背光侧 74% 的深色。渐变的中段只压一点点（10%），模拟半影带。这样行星公转到哪儿，哪一面被照亮就正确到哪儿。

## 土星环的前后遮挡

环要穿过行星本体，先画环再画行星会整圈压在行星上面，穿帮。做法是拆成两次：

1. `drawRingHalf(x, y, r, false)` —— 只画椭圆环的**后半**（角度 π→2π）
2. 画行星本体
3. `drawRingHalf(x, y, r, true)` —— 画**前半**（0→π）

环用固定倾角 -0.46 rad，不随公转旋转（真土星环指向基本恒定）。三圈不同透明度的椭圆描边叠出层次。

## 固定随机种子：resize 不洗牌

星空和小行星带都是随机生成的，但窗口一 resize 就重新随机的话，整个画面会"洗一次牌"。解法是固定种子的 LCG（线性同余生成器）：

```js
const rand = ((seed) => () => (seed = (seed * 16807) % 2147483647) / 2147483647)(20261022);
```

所有随机量（星星位置、陨石坑位置、小行星轨道）都从这同一个 `rand` 取。resize 时按同样顺序重新生成，布局完全一致。

## 小行星带与彗星

- **小行星带**：150 颗，半径卡在火星和木星轨道之间（0.515–0.565），各自独立周期，尺寸 0.4–1.2px、透明度 22%–62%
- **彗星**：椭圆轨道用极坐标方程 `r = a(1-e²)/(1+e·cosθ)`，e = 0.68，是个明显偏心的椭圆。彗尾只在近日点出现：`tailLen` 随日距缩短而拉长，方向用 `atan2` 算出**背向太阳**，渐变从头到尾淡出

## 其他细节

- **太阳**：白热核心（三层径向渐变）+ 呼吸日冕，半径按 `1 + .05·sin(t)` 缓慢脉动
- **地球特批**：带月球（角速度是公转的 13.4 倍）、一圈古铜金虚线标记环和 "EARTH · HQ" 标签——这是全站唯一的"据点"标识
- **星空两层**：静态底星 + 只对亮星做的 sin 闪烁，再叠一条斜向银河尘带渐变
- **悬停**：鼠标靠近行星时浮出名称

## 性能

面板是常驻动画，不控就是耗电大户：

- rAF 内做 30fps 节流（间隔 < 1000/30 就跳帧）
- `IntersectionObserver`：面板滚出视口就暂停
- `visibilitychange`：页面切走就暂停
- devicePixelRatio 上限 1.5，4K 屏不至于画 4 倍像素
- `prefers-reduced-motion` 用户只画静态一帧

整个太阳系 400 来行，没有依赖、没有素材，构建产物里只多了几 KB 的 JS。

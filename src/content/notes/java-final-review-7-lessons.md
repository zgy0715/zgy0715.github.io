# Java 期末复习 7 课专题

> 本文整理自 [AI-ML-Learning](https://github.com/zgy0715/AI-ML-Learning) 仓库 `lessons/java/README.md`。这个"Python 学习仓库"里藏着一套 Java 期末复习课——也是仓库语言统计里 Java 占比更高的原因。

## 课程结构

7 课，每课理论（.md）+ 可运行代码（.java）成对出现：

| 课号 | 主题 | 核心考点 |
|:----:|:----|:----|
| 第 1 课 | Java 基础入门 | 变量、数据类型、控制流程、数组、方法 |
| 第 2 课 | 面向对象编程 | 类、继承、多态、封装、抽象类、接口 |
| 第 3 课 | Java 常用 API | String、包装类、Math、异常处理 |
| 第 4 课 | 集合与泛型 | ArrayList、HashSet、HashMap、泛型 |
| 第 5 课 | I/O 流与文件 | 字节流、字符流、缓冲流、序列化 |
| 第 6 课 | 多线程与网络 | Thread、synchronized、Socket、TCP/UDP |
| 第 7 课 | 反射机制 | Class、Constructor、Method、Field |

## README 里标注的考试重点

- **第 2 课 OOP**：继承、多态、抽象类 vs 接口（必考大题）
- **第 3 课 异常处理**：try-catch-finally（选择题 + 编程题）
- **第 4 课 集合**：ArrayList、HashMap 的使用（编程题）
- **第 6 课 多线程**：Thread、synchronized（选择题 + 简答）
- **第 7 课 反射**：了解即可（选择题）

## 附赠：Java vs Python 对照表

README 末尾有一张两语言对照表（变量声明、代码块缩进 vs 花括号、集合类型、异常语法……），对在两门语言间切换很有用。

# 第 8 课：什么是机器学习

> 本文整理自 [AI-ML-Learning](https://github.com/zgy0715/AI-ML-Learning) 仓库 `lessons/python/lesson_8_ml_intro.md`。

## 一句话区分

```
传统编程：数据 + 规则 → 答案
机器学习：数据 + 答案 → 规则
```

课程里用垃圾邮件过滤器举例：写死 `if 包含"免费"` 的规则，对方改成"免~费~"就失效；而给电脑一万封标注好的邮件，它自己学出规律。

## 三种类型

| 类型 | 数据要求 | 应用场景 |
|:----:|:--------:|:--------|
| 监督学习 | 需要标注数据 | 分类、回归（房价预测、手写数字识别） |
| 无监督学习 | 不需要标注 | 聚类（客户分群、新闻归类） |
| 强化学习 | 环境交互 + 奖惩 | AlphaGo、自动驾驶、游戏 AI |

监督学习里再分：**预测数字叫回归**（房价、温度），**预测类别叫分类**（猫/狗、垃圾/正常）。

## 核心术语速记

特征（Feature，考试题目）→ 模型（Model，大脑）→ 预测（Predict，参加考试）；标签（Label）是标准答案，训练（Train）是做练习题的过程。

## 完整流程

收集数据 → 数据清洗 → 特征工程 → 选择模型 → 训练模型 → 评估模型。数据是一切的基础。

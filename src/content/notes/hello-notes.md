# 开个笔记角落

这个板块的定位改过一次。第一版我写了几篇"学习感受"，但里面为了好看加了当时并没有发生过的细节——后来全部撤掉了。

现在的规矩只有一条：**写真实的东西**。具体来说：

- 网站本身的开发记录（每次改版都有对应的 commit 可查）
- 从自己仓库的 README 和提交历史里整理出的真实进展
- 部署过程中真实踩到的坑（比如 GitHub 直连抽风、Pages 构建模式被切换）

学习心得类的内容，等 AI-ML-Learning 仓库里的练习真的推进到值得写的程度再补——仓库里有 [PROGRESS.md](https://github.com/zgy0715/AI-ML-Learning/blob/main/PROGRESS.md) 逐课追踪，进度造假在这里是活不过一次比对的。

# 开个笔记角落

这个板块的定位改过一次。第一版我写了几篇"学习感受"，但里面为了好看加了当时并没有发生过的细节——后来全部撤掉了。

现在的规矩只有一条：**写真实的东西**。具体来说：

- **课程笔记**：从 [AI-ML-Learning](https://github.com/zgy0715/AI-ML-Learning) 的课程文件（第 8-10 课、Java 7 课）提炼的要点，原文都在仓库里
- **项目拆解**：自己各个仓库的架构笔记（苍穹外卖、HRMS、像素填空、Tech Hotspot 等），对应各自 README 展开
- **网站开发记录**：每次改版都有对应的 commit 可查
- **部署踩坑**：GitHub 直连抽风、Pages 构建模式被切换这类真实故障

学习心得类的内容，等 AI-ML-Learning 仓库里的练习真的推进到值得写的程度再补——仓库里有 [PROGRESS.md](https://github.com/zgy0715/AI-ML-Learning/blob/main/PROGRESS.md) 逐课追踪，进度造假在这里是活不过一次比对的。

# 开个笔记角落

上周给室友讲 NumPy 的广播机制，我张口就是"就是形状对不上的话它会自动扩展"，他问我怎么扩展的，我卡壳了。回去翻书才把 `(m, n)` 遇到 `(n,)` 和 `(m, 1)` 两种情况的规则完整说清楚——那一刻我意识到，**做过 ≠ 会讲，会讲才算会**。

## 所以这个板块的规矩

1. **每篇必须有具体的东西**：报错信息、数字、代码片段、日期。不许写"我学到了很多"这种废话
2. **优先写卡住的地方**：顺利的部分没营养，卡住又解决的才有信息量
3. **写给三个月后的自己**：现在觉得 obvious 的细节，三个月后大概率全忘了

## 会写什么

- 机器学习的练习记录（挂在 [AI-ML-Learning](https://github.com/zgy0715/AI-ML-Learning) 仓库上）
- 这个网站每次改版的决策（为什么砍掉某个花活、为什么换个写法）
- Java 课设、Python 小脚本这些课程作业里值得记的部分

## 更新频率

不承诺。但 10 月已经排了三篇在写，至少比朋友圈更新得勤。
